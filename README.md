### Oi, sou o Fellipe

Estudo Engenharia de Software e tenho uma empresa de tecnologia em São Paulo. No dia a dia eu faço duas coisas que parecem diferentes mas acabam se encontrando: sites para clientes e sistemas internos para empresas, quase sempre resolvendo algum processo que hoje vive em planilha, e-mail ou papel.

Na web eu gosto de HTML, CSS e JavaScript puros, sem framework quando dá, e uso Supabase quando o projeto precisa de banco e login. Nas empresas trabalho com Power Apps, Power Automate, Power BI e SharePoint, montando apps de aprovação, apontamento e relatório.

**O que uso com mais frequência:** HTML · CSS · JavaScript · SQL · Supabase (Postgres) · Vercel · Power Apps · Power Automate · Power BI · SharePoint · Dataverse · C

### Projeto em destaque

**[Assembleia de Deus Belém – Parque Artur Alvim](https://github.com/fellipeaguiardev/assembleia-de-deus-pq-artur-alvim)**
Site e app (PWA) da igreja, feito para o celular. Tem Bíblia completa com leitura offline, lição da Escola Bíblica, Harpa Cristã, biblioteca com controle de empréstimos, vídeos do YouTube atualizados sozinhos e um painel em `/admin` para a equipe editar tudo sem depender de programador.
JavaScript puro, Supabase com RLS em todas as tabelas, funções na Vercel e checagem automática a cada push.

[Ver o site](https://assembleia-de-deus-pq-artur-alvim.vercel.app) · [Ver o código](https://github.com/fellipeaguiardev/assembleia-de-deus-pq-artur-alvim)
